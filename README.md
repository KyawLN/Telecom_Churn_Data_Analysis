# 📡 Telecom Churn Data Analysis

## 📄 Project Overview
This project analyzes customer data from a telecommunications company to identify the key factors contributing to customer churn (attrition). By examining demographics, usage patterns, and account information, we aim to provide actionable insights to improve customer retention.

### 👥 The Team
This project was a collaborative effort by: Kyaw Lwin Naing (me) & two of my friends

## 🎯 Key Objectives
* **Identify Churn Drivers:** Determine which factors (e.g., contract type, monthly charges, support calls) correlate most strongly with customers leaving.
* **Customer Segmentation:** Group customers based on behavior to tailor retention strategies.
* **Actionable Insights:** Provide recommendations to the business to reduce the churn rate.

## 📊 Methodology & Workflow
1.  **Data Preprocessing:** Handling missing values, encoding categorical variables, and normalizing numerical features.
2.  **Exploratory Data Analysis (EDA):** Visualizing distributions of churn vs. non-churn customers using [Matplotlib/Seaborn].
3.  **Analysis/Modeling:** Implemented Machine Learning models (Logistic Regression, Random Forest) to predict churn probability.
    
## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Seaborn
* **Tools:** Jupyter Notebook,Excel

## 📈 Key Findings
* Customers with "Month-to-Month" contracts are 40% more likely to churn.*
* High monthly charges correlate positively with churn, suggesting price sensitivity.*
* Customers with Fiber Optic internet service showed higher dissatisfaction rates.*
